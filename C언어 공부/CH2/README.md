# 📝 마크다운(Markdown) 사용법 및 표준 문법 가이드

마크다운은 텍스트 기반의 마크업 언어로, 문서를 쉽고 빠르게 구조화하여 가독성을 극대화할 수 있는 공학적 문서 작성 도구입니다.

---

## 1. 제목 (Headers)
`#` 기호의 개수로 1단계부터 6단계까지의 문서 구조 제목을 정의합니다. `#` 뒤에는 반드시 **공백(Space)**을 한 칸 두어야 하는 것이 팩트 규격입니다.

# 제목 1단계 (가장 큰 체급)
## 제목 2단계 (대분류)
### 제목 3단계 (중분류)
#### 제목 4단계
##### 제목 5단계
###### 제목 6단계 (가장 작은 체급)

---

## 2. 텍스트 강조 및 스타일 (Text Styles)
텍스트의 가시성을 높이고 핵심 키워드를 강조할 때 사용합니다.

* **굵게 (Bold):** 글자 앞뒤를 별표 2개(`**`) 또는 언더바 2개(`__`)로 감쌉니다. 예: **핵심 팩트**
* *기울임 (Italic):* 글자 앞뒤를 별표 1개(`*`) 또는 언더바 1개(`_`)로 감쌉니다. 예: *이탈릭체*
* ~~취소선 (Strikethrough):~~ 글자 앞뒤를 물결표 2개(`~~`)로 감쌉니다. 예: ~~오답 코드~~

---

## 3. 리스트 및 목록 (Lists)
데이터 파이프라인이나 공정 시퀀스를 순차적/비순차적으로 구조화할 때 사용합니다.

### ① 순서가 없는 목록
별표(`*`), 하이픈(`-`), 또는 더하기(`+`) 기호를 사용합니다.
* 데이터 생성 및 수집 (Kafka)
* 데이터 저장 및 적재 (SQLite)
* 데이터 정제 및 분석 (XGBoost)

### ② 순서가 있는 목록
숫자와 마침표(`.`)를 사용합니다. 연산 장치가 순서를 칼같이 인식합니다.
1. C 소스 코드 파일 작성 (`.c`)
2. 컴파일러 가동 (`gcc`)
3. 실행 파일 출력 (`a.out`)

---

## 4. 코드 블록 (Code Blocks)
소스 코드의 가독성을 방어하고 문법 하이라이팅을 적용하기 위한 핵심 인프라입니다.

### ① 인라인 코드
문장 중간에 키워드를 기술할 때는 백틱 기호 1개(`` ` ``)로 감쌉니다.
예를 들어 주소를 제어할 때는 `int *ptr` 포인터 변수를 매핑해야 합니다.

### ② 블록 코드 (다중 라인)
백틱 3개(``` ``` ```)로 감싸고 시작 백틱 옆에 `c`, `python`, `bash` 등 언어 이름을 명시합니다.

```c
#include <stdio.h>
int main(void) {
    printf("Hello Markdown!\n");
    return 0;
}
